# Calculator

This project is meant as a learning project for the author. It is intended to be a mobile calculator capable of all basic the basic arithmetic functions: addition, subtraction, multiplication and division.

The goals of this learning experience is to practice various programming conventions, like file modularity and structure, implement basic project management via issues, a project board, and time tracking. I also want to go through all the stages of project development from creation to deployment at the least. I have no way of knowing how or if I will be able to maintain this project after it is deployed.

I have set up a changelog file to track changes, and I have a ClickUp board to track tasks and time.
